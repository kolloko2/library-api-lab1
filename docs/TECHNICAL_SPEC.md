# Краткое техническое задание

## Тема

«Библиотека: учёт книг, авторов, филиалов, экземпляров и выдач». Тема предназначена для согласования с преподавателем и используется как сквозной проект следующих лабораторных работ.

## Функции

- ведение авторов, книг и филиалов;
- регистрация физических экземпляров с уникальным инвентарным номером;
- поиск книг по части названия и автору;
- фильтрация экземпляров по филиалу и доступности;
- выдача экземпляра читателю и возврат;
- служебная проверка работоспособности.

## Сущности и связи

- `Author 1—N Book`: у книги один автор, у автора несколько книг;
- `Book 1—N BookCopy`: книга может иметь несколько физических экземпляров;
- `Branch 1—N BookCopy`: экземпляр закреплён за одним филиалом;
- `BookCopy 1—N Loan`: экземпляр участвует во многих выдачах во времени, активна не более одной.

## Обязательные правила

1. ISBN книги, имя автора, имя филиала и инвентарный номер уникальны.
2. Книгу нельзя создать без существующего автора, экземпляр — без книги и филиала.
3. Выдать можно только доступный экземпляр.
4. Один читатель может иметь не более `MAX_ACTIVE_LOANS` активных выдач (по умолчанию 5).
5. Уже возвращённую выдачу нельзя вернуть повторно.

## Ошибки

- `404 Not Found` — связанная сущность не найдена;
- `409 Conflict` — нарушена уникальность или правило выдачи;
- `422 Unprocessable Entity` — тело/параметры запроса не прошли проверку;
- `500 Internal Server Error` — непредвиденная ошибка сервера.

Ответы ошибок имеют стандартное поле FastAPI `detail`.

## Хранение и ограничения

Данные хранятся в реляционной БД, адрес задаётся `DATABASE_URL`. Для локальной работы используется SQLite; архитектура допускает дальнейший переход на PostgreSQL. Секреты хранятся только в переменных окружения и не фиксируются в Git. Внешние ключи обеспечивают целостность связей, даты выдачи и возврата хранятся в UTC.
